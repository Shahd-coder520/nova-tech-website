# منصة شركة Nova Tech الرسمية 🌐

مستودع الكود الخاص بالموقع الرسمي لشركة Nova Tech، والذي يضم واجهات تعريفية بخدمات ومنتجات الشركة، بالإضافة إلى نظام مدونة متكامل ولوحة تحكم مخصصة للإدارة (Admin Dashboard)[cite: 12, 20]. تم بناء هذا المشروع ليكون منصة متكاملة تقدم حلولاً برمجية وأنظمة متطورة[cite: 12].

## ✨ الميزات الأساسية (Key Features)

* **واجهات مستخدم تفاعلية:** عرض احترافي لمنتجات الشركة الرقمية الرئيسية مثل تطبيق "لوميو"، نظام "بيراميد" المحاسبي، ونظام "رعاية" الطبي[cite: 13].
* **معرض الخدمات والنجاحات:** قسم مخصص لاستعراض خدمات تطوير الويب، تطبيقات الهواتف الذكية، إدارة المشاريع، مع تسليط الضوء على قصص النجاح مثل تطبيق "وصيلك"[cite: 14].
* **نظام مدونة متكامل (Blog):** قسم ديناميكي لعرض أحدث المقالات التقنية وإصدارات الشركة بتصميم عصري (Cards)[cite: 16, 17]، مع صفحات مخصصة لقراءة تفاصيل كل مقال بوضوح[cite: 18].
* **لوحة تحكم محمية (NOVA PANEL):** لوحة تحكم مخصصة للمسؤولين تمنع وصول أي شخص بدون تسجيل دخول مسبق[cite: 20].
* **نظام مصادقة آمن:** واجهة تسجيل دخول مخصصة (Login) للوصول إلى لوحة الإدارة[cite: 19].
* **محرر مقالات متقدم:** واجهة "إضافة مقال جديد" مدمجة في لوحة التحكم، تحتوي على محرر نصوص غني (Rich Text Editor) لتنسيق المحتوى، التحكم بحجم ونوع الخط، وإدراج الروابط والصور[cite: 21].
* **نموذج تواصل مباشر:** صفحة مخصصة تتيح للعملاء إدخال بياناتهم وتحديد نوع الخدمة وإرسال الطلب مباشرة عبر تطبيق واتساب[cite: 15].

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **إطار العمل (Framework):** Next.js لتطوير واجهات المستخدم وتوجيه الصفحات[cite: 12, 13, 14].
* **المصادقة والحماية (Authentication):** NextAuth لتأمين نظام تسجيل الدخول وحماية مسارات لوحة التحكم[cite: 19, 20].
* **قاعدة البيانات (Database):** SQL (محلية) لتخزين وإدارة مقالات المدونة.
* **محرر النصوص (Rich Text Editor):** Lucid React المدمج في لوحة التحكم لإنشاء وتنسيق محتوى المدونة[cite: 21].
* **تصميم الواجهات (UI/UX):** واجهات متجاوبة بتصميم ليلي (Dark Theme) يعكس الهوية البصرية التقنية للشركة[cite: 12, 13].
